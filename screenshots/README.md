# ShopEase Storefront Screenshots Guide

This directory holds visual references and previews of the ShopEase application across its key responsive pages:

## Recommended Screenshots to Capture

1. **`01-homepage.png`**:
   - Hero banner with "Discover Quality. Shop With Ease."
   - Popular Categories cards.
   - Featured products and promotional banner.

2. **`02-products-catalog.png`**:
   - Shop page showing search bar, category filter pills, price range inputs, and sort dropdown.
   - Responsive product cards with Indian Rupee (₹) pricing, ratings, and discount tags.

3. **`03-product-detail.png`**:
   - Large product image preview.
   - Price, discount amount, stock indicator, specifications table, and customer reviews.
   - Quantity selector bounded by stock and "Add to Cart" button.

4. **`04-cart-page.png`**:
   - Shopping cart listing with item thumbnails, quantities, line totals, and remove buttons.
   - Order summary card displaying Free Shipping progress indicator and checkout button.

5. **`05-checkout-form.png`**:
   - Responsive shipping address form with validation errors.
   - Order summary sidebar and simulated checkout disclaimer banner.

6. **`06-order-success.png`**:
   - Success checkmark icon.
   - Generated order ID (e.g. `SE-XXXX-XXXX`).
   - Customer shipping details and purchased items receipt.

7. **`07-mobile-responsive.png`**:
   - Mobile view (375px) showing hamburger menu, mobile filter drawer, and stacked product cards.
